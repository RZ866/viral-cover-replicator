# 差异化原创规则

原创重构保留的是光影塑形、空间层次、视觉重心等摄影原理，不保留他人独特的道具组合、场景叙事和标志性构图。

三套方案必须分别改变至少三个维度：场景目的、主体与环境关系、构图骨架、光线动机、道具语义、色彩关系。内部检查若两套方案只有颜色或道具名称变化，判定失败并重做。

- A 低成本差异化：复用现有材料，改变背景、道具关系和局部构图。
- B 场景差异化：围绕真实使用情境重写叙事、机位和光线。
- C 深度原创：只继承抽象摄影原理，重新设计全部视觉组合。

原创成片同时检查摄影质量和差异证据。结论仅允许：差异充分；有一定差异但需加强；差异不足建议重设；信息不足无法判断。不能输出平台官方原创分或保证过审。
